# 🎨 DESIGN & INTERACTION PRINCIPLES (Emil Kowalski Philosophy)

Этот документ фиксирует стандарты дизайна, анимаций и взаимодействия для приложения **«Заказ Снеков»**. Все последующие изменения и новые компоненты должны следовать этим правилам.

---

## 1. Кинематика и кривые анимации (Tokens)

Все анимации используют токены из `:root`, определённые в `css/styles.css`:

```css
:root {
  --ease-out: cubic-bezier(0.23, 1, 0.32, 1);       /* Быстрый вход, мягкое торможение для UI */
  --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);   /* Перемещение элементов внутри экрана */
  --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);    /* Физика шторки iOS (Vaul) */
  --dur-press: 110ms;                               /* Мгновенная реакция кнопок */
  --dur-fast: 160ms;                                /* Микроиндикаторы, переключение табов */
  --dur-normal: 220ms;                              /* Модалки, попапы, диалоги */
  --dur-sheet: 320ms;                               /* Bottom Sheet шторка заказа */
}
```

### Запреты:
- **Никаких `transition: all`:** Всегда указываются явные свойства (`transform`, `opacity`, `background-color`, `border-color`).
- **Никаких `ease-in`:** `ease-in` делает интерфейс вялым, задерживая отклик в начальный момент внимания.
- **Никаких анимаций свыше 300ms для обычного UI:** (исключение — шторка корзины и тосты).

---

## 2. Тактильный отклик (Touch & Active States)

- **Мгновенный отклик на нажатие (`:active`):**
  Кнопки подтверждают нажатие в момент касания пальцем (`pointerdown`), а не отпускания:
  ```css
  .button:active {
    transform: scale(0.97);
    transition-duration: var(--dur-press);
  }
  .stepper-btn:active {
    transform: scale(0.95);
    transition-duration: 90ms;
  }
  ```
- **Защита от 300ms задержки:**  
  Все интерактивные элементы имеют `touch-action: manipulation;` и `-webkit-tap-highlight-color: transparent;`.

---

## 3. Мобильный слой (Mobile Native Rules)

- **Минимум 16px на полях ввода:** `font-size: 16px;` на `.search-input` и `.form-control` полностью предотвращает нежелательный зум в iOS Safari без необходимости вредоносного `user-scalable=no`.
- **Защита от залипающего Hover:**  
  Стили `:hover` изолированы через `@media (hover: hover) and (pointer: fine)`. На телефонах фото открывается строго по клику, исключая залипание 280px попапа.
- **Изоляция скролла:**  
  `overscroll-behavior-y: none;` на `html, body` исключает случайный системный pull-to-refresh. Внутри шторки — `overscroll-behavior: contain;`.
- **Высота 100dvh:**  
  Шторки и модальные окна используют `max-height: 90dvh;` с фоллбэком на `90vh`, адаптируясь под сворачивание адресной строки Safari.
- **Безопасные зоны iPhone:**  
  Шапка использует `padding-top: max(12px, env(safe-area-inset-top));`.

---

## 4. Физика жестов (Bottom Sheet / Drawer)

Шторка корзины `#orderModal` реализует 2 фазы:
1. **Фаза слежения (Track):** Палец прижат — смещение шторки следует 1:1 без кривых и задержек (`transition: none; transform: translateY(Ypx);`). При попытке тянуть вверх применяется резиновое сопротивление (`Rubber-banding`).
2. **Фаза отпускания (Release):** Если палец отпущен при смещении > 100px или скорости `velocity > 0.4` (быстрый смах), шторка закрывается. Иначе — возвращается в исходное состояние по кривой `--ease-drawer`.

---

## 5. Типографика и цифры

Для чисел (граммовка, вес, кратность) используется `font-variant-numeric: tabular-nums;`, чтобы при изменении количества кнопки не плясали по ширине.
