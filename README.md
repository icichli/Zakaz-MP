# 🍺 Система онлайн-заказа снеков для пивных магазинов

Минималистичное, быстрое веб-приложение (PWA) для удобного формирования заказов снековой продукции (гренки, сухари, мокрые снеки, орехи и др.) прямо с телефона или компьютера.

---

## 🚀 Основные возможности

1. **Мобильный интерфейс (Touch-Friendly):**
   - Крупные кнопки `+` и `-` под палец, автоматически подстраивающиеся под кратность фасовки каждого товара (1 кг, 0.5 кг, 3 шт, 1 кор, 1 уп и т.д.).
   - Возможность нажать на само число и ввести количество вручную с клавиатуры.
2. **Умный поиск:**
   - Быстрый живой поиск по названию продукции.
3. **Группировка по разделам и вкладкам:**
   - Включает **все 14 тематических вкладок вашей Google Таблицы (389 товаров)** + раздел «Все товары»:
     - 🥖 **Гренки весовые** (72 поз.)
     - 🧀 **Сыры сухие** (6 поз.)
     - 🏭 **Снеки заводские** (44 поз.)
     - 🥜 **Орехи** (63 поз.)
     - 🌮 **Начос & лаваши** (11 поз.)
     - 🥫 **Соусы** (6 поз.)
     - 🐟 **Рыбные снеки** (54 поз.)
     - 🧀 **Сыры** (32 поз.)
     - 🥩 **Мясные снеки** (18 поз.)
     - 🍖 **Мясные завод** (19 поз.)
     - 🧻 **Расходники** (42 поз.)
     - 🥡 **Контейнеры** (7 поз.)
     - ❄️ **Заморозка** (10 поз.)
     - 🍬 **Вкусняшки** (5 поз.)
     - ✏️ **Свободный ввод**
   - В выдаче отображается строго наименование товара и кратность (фасовка). Лишняя информация (бренды, стили) скрыта для максимальной чистоты и скорости работы.
4. **Окно свободного ввода:**
   - Добавление редких или нестандартных позиций вручную (название, количество, единица измерения).
5. **Надежное сохранение (LocalStorage):**
   - Заказ сохраняется на устройстве в реальном времени. Перезагрузка страницы или закрытие вкладки не сбросят прогресс.
   - Кнопка «Сброс» с подтверждением для очистки перед новым заказом.
6. **Выгрузка и отправка заказа:**
   - **📋 Скопировать для WhatsApp / Telegram:** формирует аккуратный структурированный текст, разбитый по разделам, с подсчетом общего веса и позиций.
   - **📱 Поделиться:** отправка напрямую в мессенджер через системное меню мобильного телефона.
   - **📥 Excel (.xlsx):** мгновенное скачивание файла таблицы с заказом без обращения к сторонним серверам.
7. **Живая синхронизация с Google Таблицей:**
   - Кнопка **🔄** в шапке загружает актуальные данные из вашей публичной Google Таблицы. Приложение само подстраивается под новые строки и вкусы!
8. **Автономность (PWA & Offline):**
   - Приложение работает офлайн даже без интернета (кэширование через Service Worker).
   - Можно установить как приложение на домашний экран смартфона (Android и iOS).

## 📂 Структура файлов

```text
├── index.html              # Основная веб-страница приложения
├── css/
│   └── styles.css          # Стилизация и адаптивный дизайн
├── js/
│   └── app.js              # Вся логика: шаги, корзина, поиск, экспорт, синхронизация
├── vendor/
│   └── xlsx.full.min.js    # Локальная библиотека SheetJS для Excel
├── icons/                  # Иконки для PWA и ярлыка на телефоне
├── manifest.json           # Манифест PWA
├── sw.js                   # Service Worker для офлайн-работы
├── cleaned_catalog.xlsx    # Очищенная и структурированная таблица для Google Таблиц
└── cleaned_catalog.csv     # Таблица в формате CSV
```

## 🌐 Как развернуть на GitHub Pages (Бесплатно за 2 минуты)

1. Создайте новый репозиторий на **[GitHub](https://github.com/new)** (например, с именем `snacks-order`).
2. Загрузите все файлы из этой папки в репозиторий (через Git или кнопку `Add file` -> `Upload files`).
3. Перейдите в **Settings** (Настройки репозитория) ➔ слева раздел **Pages**.
4. В блоке **Branch** выберите ветку `main` (или `master`), папку `/ (root)` и нажмите **Save**.
5. Через 1 минуту GitHub выдаст готовую ссылку вида:  
   `https://<ваш_логин>.github.io/snacks-order/`

## 📲 Как установить на телефон (как приложение с иконкой)

* **На Android (Chrome):**
  1. Откройте ссылку на сайте в Google Chrome.
  2. Нажмите три точки меню в правом верхнем углу ➔ **«Установить приложение»** (или «Добавить на главный экран»).
* **На iPhone (Safari):**
  1. Откройте ссылку в браузере Safari.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх) ➔ выберите **«На экран «Домой»»**.
