# 🍺 Система онлайн-заказа снеков для пивных магазинов

Минималистичное, быстрое веб-приложение (PWA) для удобного формирования заказов снековой продукции (гренки, сухари, мокрые снеки, орехи и др.) прямо с телефона или компьютера.

---

## 🚀 Основные возможности

1. **Мобильный интерфейс (Touch-Friendly):**
   - Крупные кнопки `+` и `-` под палец, автоматически подстраивающиеся под кратность фасовки каждого товара (1 кг, 0.5 кг, 3 шт, 1 кор, 1 уп и т.д.).
   - Возможность нажать на само число и ввести количество вручную с клавиатуры.
2. **Умный поиск:**
   - Быстрый живой поиск по названию продукции.
3. **Переключение поставщиков (Мульти-поставщик):**
   - Удобный переключатель в шапке разделяет ассортимент по независимым поставщикам:
     - 🍺 **Снеки и закуски** (325 поз.: Гренки, Сыры, Орехи, Начос, Соусы, Рыба, Мясные)
     - 🧻 **Расходники и тара** (43 поз.: Расходники, Контейнеры)
     - 🎪 **Ярмарка** (15 поз.: Заморозка, Вкусняшки)
     - 🥔 **Пивные закуски** (15 поз.: Pringles)
   - **Автоматическое считывание из Google Таблицы:** приложение само определяет поставщиков (через колонку `Поставщик` в таблице или отдельный лист `Поставщики`).
4. **Раздельные корзины и отправка заказов:**
   - Для каждого поставщика ведётся свой независимый заказ (вы можете одновременно набирать снеки и расходники, ничего не перемешается).
   - Внутри корзины отображается заказ выбранного поставщика с возможностью переключения в один клик.
   - **📋 Скопировать для WhatsApp / Telegram:** формирует сообщение строго для выбранного поставщика с подсчетом веса и позиций.
   - **📥 Excel (.xlsx):** выгружает чистый файл таблицы конкретного поставщика (`Заказ_Снеки.xlsx`, `Заказ_Расходники.xlsx`).
5. **Окно свободного ввода:**
   - Добавление редких или нестандартных позиций вручную с привязкой к активному поставщику.
6. **Надежное сохранение (LocalStorage):**
   - Заказы всех поставщиков сохраняются на устройстве в реальном времени. Перезагрузка страницы или закрытие вкладки не сбросят прогресс.
   - Кнопка «Сброс» позволяет очистить заказ только текущего поставщика или все заказы сразу.
7. **Живая синхронизация с Google Таблицей:**
   - Кнопка **🔄** в шапке загружает актуальные данные из вашей публичной Google Таблицы. Приложение само подстраивается под новые строки и вкусы!
8. **Автономность (PWA & Offline):**
   - Приложение работает офлайн даже без интернета (кэширование через Service Worker).
   - Можно установить как приложение на домашний экран смартфона (Android и iOS).

## 🥔 Автопарсинг Pringles из каталога поставщика («Пивные закуски»)

В проекте настроен автоматический парсинг наличия чипсов **Pringles** с сайта поставщика (`пивныезакуски.рф`) прямо в отдельную вкладку **`Pringles`** Google Таблицы «БАЗА СНЕКИ»:
- Скрипт: [`scripts/apps-script/pringles_parser.gs`](file:///c:/Users/icich/ЗАКАЗЫ%20СНЕКОВ/scripts/apps-script/pringles_parser.gs)
- Парсит страницу категории без цен и без переходов по товарам.
- Фильтрует американские позиции (158 г) и оставляет актуальные европейские фасовки (165 г, 40 г, 160 г и др.).
- В Google Таблице формирует колонки: `Наименование`, `Бренд`, `Вид продукта`, `Фасовка`, `Поставщик`, `Обновлено`.
- Все позиции автоматически закреплены за поставщиком **«Пивные закуски»**.

## 🌐 Как развернуть на GitHub Pages (Бесплатно за 2 минуты)

1. Создайте новый репозиторий на **[GitHub](https://github.com/new)** (например, с именем `snacks-order`).
2. Загрузите все файлы из этой папки в репозиторий (через Git или кнопку `Add file` -> `Upload files`).
3. Перейдите в **Settings** (Настройки репозитория) ➔ слева раздел **Pages**.
4. В блоке **Branch** выберите ветку `main` (или `master`), папку `/ (root)` и нажмите **Save**.
5. Через 1 минуту GitHub выдаст готовую ссылку вида:  
   `https://<ваш_логин>.github.io/snacks-order/`

## 📲 Как установить на телефон (как приложение с иконкой)

* **На Android (Chrome):**
  1. Откройте ссылку на сайте в Google Chrome.
  2. Нажмите три точки меню в правом верхнем углу ➔ **«Установить приложение»** (или «Добавить на главный экран»).
* **На iPhone (Safari):**
  1. Откройте ссылку в браузере Safari.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх) ➔ выберите **«На экран «Домой»»**.
